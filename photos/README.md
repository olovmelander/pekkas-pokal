# Foton

Lägg bilder här med årtalet som filnamn:

```
2025.jpg
2024.jpg
2023.jpg
```

Bilden visas automatiskt högst upp på det årets kort i Historik och i
resultatrutan när man klickar på året. Saknas en bild händer ingenting.

Tips: liggande format, ca 1200 px brett, komprimerat till under ~300 kB.
